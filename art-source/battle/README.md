# Battle artwork sources

Original generated PNGs are retained here outside Vite's public output. Their prompts and generation provenance are recorded in docs/battle-art-prompts.md, docs/battle-hero-prompts.md and docs/battle-location-prompts.md. Historical prompt records refer to the original public PNG destination; sources now live here.

Run `python3 scripts/package_battle_art.py` from the repository root with Pillow/WebP support to create lossless runtime WebP assets. The script builds power-of-two Lanczos derivatives capped at 768px for actors and 1536px for locations, then verifies exact decoded RGBA equality against each derivative. It writes docs/battle-art-package.json and src/data/battleTextureSources.json, preserving original logical dimensions for renderer coordinates. Original PNGs remain unchanged. The Golem atlas has a separate pack_actor_atlas.py pipeline which packs four poses in a 2×2 grid, builds a derivative capped at 2048px, and exports original frame coordinates with source-resolution metadata. Runtime manifests reference public/assets/battle/*.webp. Future artwork changes should start from these originals, then regenerate their runtime encodings.
